A fast, focused Git client.

Keel is a desktop source-control application named after a ship's keel: the structural backbone that gives a vessel stability. The product aims to be a reliable foundation for everyday Git work — clear, quick, and uncluttered — without turning into an IDE.

**Status:** Planning. This repository currently holds product and design documentation only. No application code has been published yet.
